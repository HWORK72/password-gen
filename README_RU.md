Легковесный веб-сервис для генерации криптографически стойких паролей с настраиваемым уровнем энтропии и защитой от перебора методом brute-force.

### Архитектурные особенности:
* **Криптографическая случайность:** Использование модуля `secrets` для генерации случайных последовательностей на основе системного генератора случайных чисел (CSPRNG), устойчивого к статистическому анализу.
* **Гибкая конфигурация энтропии:** Настраиваемый пул символов (верхний и нижний регистр, цифры, специальные знаки, пробелы) с математической гарантией сложности пароля.
* **REST/Web-интерфейс:** Реализация микросервисной архитектуры на Flask для мгновенной генерации через браузер.
* **Облачный деплой:** Конфигурация для изолированного развертывания в среде PythonAnywhere.

### Стек технологий:
* Python 3.12
* Flask (Веб-микросервис)
* Python Secrets / Random (Криптографический генератор)
* HTML5 / CSS3 (Клиентский интерфейс)
